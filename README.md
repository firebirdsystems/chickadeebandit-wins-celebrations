# Wins & Celebrations

A [Chickadee Bandit](https://chickadeebandit.com/app-library/wins-celebrations) app.

Post a win — a grade, goal, or milestone — and let the whole family cheer you on.

## Features

- Post wins with a note.
- Emoji reactions and congratulations.
- Scoped to the household.

## Install

In your hub, go to **Apps → Install from URL** and paste:

```
https://github.com/firebirdsystems/chickadeebandit-wins-celebrations/releases/latest/download/bundle.json
```
